# Al Ghaith Laundry Management

Arabic, mobile-friendly laundry tracking app for company employees, bedding, contractors, housing supervisors, and periodic expense reports. Flask application with Supabase PostgreSQL in production and SQLite for local development. Deploy from GitHub to Render using the included `render.yaml`.

See [README_AR.md](README_AR.md) for full Arabic setup, Supabase/GitHub/Render deployment, Android PWA installation, and user instructions.
